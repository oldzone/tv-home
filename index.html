⚡ Paylaş menüsüne ekle (Kısayol)
  1. Kestirmeler uygulamasını aç → sağ üstte +.
  2. Ad: TV'ye Gönder. Altta ⓘ → Paylaşma Ekranında Göster'i aç, tür olarak URL ve Metin seç.
  3. URL'nin İçeriğini Al eylemini ekle. URL: https://ntfy.sh/tvhome-KOD
  4. Eylemi genişlet: Yöntem POST, İstek Gövdesi JSON → Yeni Alan Ekle → Metin: anahtar url, değer Kestirme Girdisi.
  5. Bitti. Safari / YouTube / Google'da Paylaş → TV'ye Gönder de, TV'de 4 saniye sonra açılır.
