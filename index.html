⚡ Safari'de "TV'ye Gönder" butonu (bir kerelik kurulum)
  1. Kestirmeler uygulamasını aç → sağ üstte +.
  2. Adını TV'ye Gönder yap. Altta ⓘ → Paylaşma Ekranında Göster'i aç (tür: URL, Metin).
  3. URL'nin İçeriğini Al eylemini ekle. URL:
  4. Eylemi genişlet: Yöntem POST, İstek Gövdesi JSON → Yeni Alan → Metin: anahtar url, değer Kestirme Girdisi.
  5. Bitti. Google'da bulduğun sayfada Paylaş → TV'ye Gönder: TV'de açılır.
📺 TV ekranı kendiliğinden açılsın
  1. TV'de Play Store'dan Fully Kiosk Browser'ı kur.
  2. Ayarlar → Web Content Settings → Start URL:
  3. Device Management → Launch on Boot açık. TV açılınca ekran gelir.
  4. Telefondan "TV'ye Bağlan" ile öne getirme ve uygulamaları doğrudan açma için: Advanced Web Settings → Enable JavaScript Interface (PLUS). Bu özellik Fully'nin ücretli PLUS lisansını ister.
